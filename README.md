# NS Frontend Mobile

Expo / React Native mobile app for the Massage Booking application.

## Tech Stack
- Expo SDK 52
- React Native 0.76
- NativeWind (Tailwind CSS)
- Zustand (state management)
- React Query (data fetching)
- Expo Router (navigation)

## Quick Start

```bash
npm install
export EXPO_PUBLIC_API_URL=http://localhost:5000
npm start
```

Then press `w` for web, or scan QR with Expo Go.

## Features
- Client: Book appointments, view history, manage profile
- Therapist: Manage schedule, availability, walk-ins
- Push notifications via Expo
